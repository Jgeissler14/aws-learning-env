# AWS Learning Environment

This repository contains simple examples for Ansible, Packer, and Terraform. It is designed as a hands-on lab that you can follow along with the accompanying video tutorial.

## Contents
- `ansible/` – sample Ansible playbook and configuration
- `packer/` – example Packer template
- `terraform/` – basic Terraform files
- `docs/ansible-playbook-tutorial.md` – step-by-step instructions for creating your own playbook

## Getting Started
1. Clone this repository.
2. Follow the [Ansible Playbook Tutorial](docs/ansible-playbook-tutorial.md) to learn how to build and run a playbook. The guide includes advanced sections on variables, loops, and roles.
3. Explore the `packer` and `terraform` folders for additional automation examples.

Feel free to modify the examples to suit your own learning environment.
